# Mirrored Groups

## Definition

A mirrored group is a number string that reflects around a midpoint, or appears elsewhere in reverse order.

Examples:
- 1221
- 3553
- 58385
- ABCCBA-style structures if alphanumeric systems are later added

## Why this motif matters

Mirroring can appear in:
- body groups
- repeated call-up segments
- paired group constructions
- frequency sequences
- schedule echoes

## Operational explanations

- coincidence
- formatting convenience
- duplicated payload
- forward / reverse checks
- human memorability

## Symbolic readings

- reflection
- return
- self-reference
- duality
- inversion
- hidden symmetry

## How to log it

Suggested fields:
- station
- exact group
- mirrored type (full / partial / reverse-pair)
- context (header / body / outro / schedule)
- evidence score
