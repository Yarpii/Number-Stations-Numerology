# Zero-Heavy Groups

## Definition

A zero-heavy group is a numeric unit where zero is unusually prominent.

Examples:
- `000`
- `00000`
- `10000`
- `92000`
- `000 000`

## Why this motif matters

Zero-heavy groups often feel meaningful because zero can function both mathematically and symbolically:
- placeholder
- null value
- empty set
- reset
- closure
- silence marker

## Operational explanations

- null traffic
- fixed padding
- standard outro
- simplified no-message indicator
- machine-friendly formatting

## Symbolic readings

- void
- concealment
- erasure
- stillness
- completion through emptying

## Strong starter example

The Russian 7 operator family, including V07, is documented by Priyom as using `000` call-ups for null messages and `000 000` outro structures.

## Logging template

- station
- full zero-heavy string
- role (header / body / outro / null marker)
- null or full transmission
- evidence score
