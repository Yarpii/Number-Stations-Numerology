# Evidence Scale

This repository uses a simple evidence scale so readers can quickly see what is documented and what is exploratory.

## Scale

### 0 — Pure speculation
No logged examples yet.  
A symbolic idea or pattern category exists only as a possibility.

### 1 — Anecdotal hint
One example or an unsourced claim exists, but not enough to generalize.

### 2 — Limited observation
A pattern appears in a small number of logged cases or one station profile.

### 3 — Repeatable pattern
The pattern appears multiple times and can be re-described by another researcher using the same source set.

### 4 — Strongly supported pattern
The pattern appears across multiple logs, schedules, or station pages and has a stable definition.

### 5 — Operationally robust
The pattern is strongly documented and a practical explanation is better supported than symbolic speculation.

## How to score an entry

Ask:
- how many examples exist?
- are the sources primary, archival, or community-curated?
- can the pattern be reproduced?
- is the pattern stable across time?
- is the pattern better explained by procedure?

## Example use

| Claim | Score | Reason |
|---|---:|---|
| V07 uses three repeated transmissions 20 minutes apart | 4 | documented as a stable schedule feature |
| 000 000 in V07 should be read as mystical emptiness | 1 | symbolic interpretation exists, but proof of intent is weak |
| HM01 counter progression reflects renewal cycles | 2 | pattern exists, meaning remains interpretive |
| E03 5-digit formatting is a procedural standard | 5 | strongly supported by station format documentation |

## House rule

A strong **pattern** score does not automatically create a strong **symbolic meaning** score.
