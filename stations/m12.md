# M12 — Morse Station Case

## Summary

M12 represents a Morse-format station family and widens this repository beyond voice-only traffic. Including M12 is important for testing whether numeric motifs survive mode changes between spoken and keyed transmissions.

## Documented profile

- **Enigma ID:** M12
- **Mode:** Morse
- **Status:** historically monitored
- **Core feature:** grouped coded traffic in keyed format

## Why M12 matters here

M12 allows cross-mode comparisons:

- spoken versus keyed grouping
- marker behavior in non-voice formats
- transmission rhythm without speech cadence

## Observed numeric functions

### 1. Grouped coded payloads
Even in Morse, message segmentation still creates numeric analyzable units.

### 2. Repeat behavior
Repeated sequences can be logged as structural redundancy rather than semantic emphasis.

### 3. Slot persistence
Historical slots allow coarse schedule-pattern mapping in a non-voice context.
