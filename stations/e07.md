# E07 — English Man

## Summary

E07 ("English Man") is one of the best-known active English-language voice stations. It is useful in this project because it combines a strict message template with frequent schedule reuse, letting us test whether repeated numeric forms are purely operational or drift into motif-level behavior.

## Documented profile

- **Enigma ID:** E07
- **Language:** English
- **Status:** active in monitoring logs
- **Mode:** voice (USB in many logs)
- **Format note:** call-up + message groups in fixed-size structure
- **Common research value:** rich archive depth across many years

## Why E07 matters here

E07 extends the repository beyond "classic but inactive" examples by adding an active-format comparison point with:

- recurring call-up behavior
- repeatable group-size conventions
- heavy schedule regularity
- enough monitoring volume for cross-month pattern checks

## Observed numeric functions

### 1. Structured group traffic
E07 uses fixed-length number groups, supporting direct comparison with E03-style grouping logic.

### 2. Call-up persistence
Repeated call-up identifiers let researchers test whether some IDs recur more than random expectation.

### 3. Repeat-slot scheduling
Dense schedule grids create measurable weekly and monthly recurrence patterns.

## Interpretive notes

- **Strong claim:** fixed formatting and schedule recurrence are operationally documented.
- **Open claim:** repeated call-up digits may create symbolic salience for listeners without proving operator intent.
